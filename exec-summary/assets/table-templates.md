# Table template library

Ready-to-use Markdown structures. Copy and adjust to the number of supporting points.

---

## One-page summary skeleton

```
[Title stating the conclusion, not the topic]

[Conclusion / answer — 1-2 sentences]

Supporting points:
1. [Point] — [fact/data it rests on]
2. [Point] — [fact/data it rests on]
3. [Point] — [fact/data it rests on]

What follows: [implication / decision / risk to watch]

Source: [pointer to the full document]
```
