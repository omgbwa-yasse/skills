# .docx style guide — apply only when the user asks for a Word file

Read `/mnt/skills/public/docx/SKILL.md` first. This guide applies on top of it, unless the user's
organisation imposes its own graphic charter — in which case theirs prevails: ask before generating.

---

## File structure — job description (external publication)

```
Header
  → Organisation name/logo (if supplied)
  → Job title
  → Location, contract type, reporting line

Team context                           (2-3 sentences)
Main duties                            (numbered list, priority order)
Essential skills / Nice-to-have        (two clearly separated lists)
What is offered
Recruitment process and timeline
Contact / how to apply
```

## File structure — interview scorecard (internal HR file)

```
Header block — candidate, role, date, interviewer(s)
Per-competency table — question, score, note
Comparative summary (if multiple candidates)
Recommendation
```

## Styles

| Element | Value |
|---------|-------|
| Body text | Arial or Calibri 11 pt |
| Job title | 16 pt bold |
| Section headings | 12 pt bold |
| Essential vs. nice-to-have | Two distinct bullet styles or a two-column layout — never merged into one list |
| Scorecard table header | Bold, light grey fill |

## Layout rules

- Job descriptions for external publication carry no internal-only content (budget bands unless the
  organisation discloses them, internal process jargon, evaluator names).
- Scorecards and candidate summaries are internal documents: mark them accordingly and never generate
  them for external circulation.

## File naming

`job-description_[role-title]_[YYYY-MM-DD].docx`
`scorecard_[role-title]_[candidate-initials]_[YYYY-MM-DD].docx`
